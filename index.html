Platform Methodology

A transparent, data-driven pipeline designed for quantitative analysis.

1. Data Aggregation
We compile comprehensive historical trading data alongside relevant financial news coverage for each tracked equity.
2. Sentiment Extraction
Natural Language Processing techniques evaluate news headlines to generate a numerical polarity score, ranging from strongly bearish to strongly bullish.
3. Statistical Modeling
Both traditional Linear Regression and multi-layer Neural Networks process the fused datasets to identify underlying price action correlations.
4. Price Forecasting
The trained models output a projected next-day Last Traded Price (LTP), providing a statistical baseline for your market strategy.

Project Overview

About The ShareSathi Project

ShareSathi was developed to provide a comprehensive, data-backed approach to stock market analysis. By combining traditional technical analysis concepts with modern prediction algorithms and sentiment extraction, this system aims to demonstrate how continuous data streams can enhance trading decisions.

Predictive Models
We train Linear Regression and Neural Network models using historical market data to forecast short-term and long-term price movements.
Data-driven decisions
Use real historical stock and sentiment data to compare Linear Regression and ANN predictions for each company.
Trusted analytics
Sentiment signals, prediction scores, and chart analytics help create a credible investor-facing experience.
